# Cybersecurity Incident & Vulnerability Tracking System (CIRVTS)

## Project Overview

The Cybersecurity Incident & Vulnerability Tracking System (CIRVTS) is a database project developed by Team 1 Cybersecurity.

The database is designed for Apex Financial Services, a fictional financial institution that manages sensitive customer information, banking applications, and internal IT infrastructure.

The purpose of CIRVTS is to provide a centralized database for tracking cybersecurity incidents, identifying vulnerabilities, managing IT assets, and monitoring remediation activities.

## Problem Statement

Organizations that manage large amounts of sensitive information must continuously monitor their systems for security threats and vulnerabilities.

Without a centralized database, security information may be stored across spreadsheets, emails, and separate tracking systems.

This makes it difficult for employees to identify affected systems, track unresolved vulnerabilities, and determine who is responsible for addressing security incidents.

CIRVTS aims to address these problems by organizing cybersecurity information in one database.

## Project Objectives

The main objectives of CIRVTS are:

1. Track reported cybersecurity incidents and their current status.
2. Maintain information about company IT assets.
3. Record vulnerabilities discovered during security assessments.
4. Identify employees responsible for investigating incidents and performing remediation.
5. Track remediation activities and resolution progress.
6. Help security teams retrieve information about unresolved incidents and vulnerabilities.
7. Support reporting and compliance reviews.

## Intended Users

### Security Incident Analysts

Security analysts will use the database to review reported incidents, identify affected systems, monitor incident severity, and track investigation progress.

### IT Systems Administrators

IT administrators will use the database to identify vulnerable systems, review remediation assignments, and track patching activities.

### Compliance and Risk Auditors

Compliance personnel will use the database to review historical security incidents, remediation records, and information relevant to security audits.

## Expected Benefits

CIRVTS is intended to improve how cybersecurity information is stored and managed.

By using a relational database, the organization can reduce duplicate information, maintain consistent records, and make it easier for employees to retrieve information.

The system can also help security teams prioritize unresolved vulnerabilities and improve coordination between departments.

## Project Status

CIRVTS is currently an academic database development project.

The team is working on database requirements, design, normalization, table relationships, and SQL development.

The proposed database structure may change as the team continues developing the project.
